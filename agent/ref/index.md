## Reference topics

`./fh help TOPIC` prints a topic; `./fh help ACTION` an action's arguments.

- `moving-items`, items by hand: `transfer`, `collect`, `feed`, `refuel`, `pickup`, `mine`, `rotate`, `repair`,
  `inventory`, `craft`, `cancel_craft`, `deliver`.
- `building`, placing, removing (landfill, tiles): `build`, `place_ghosts`, `construct`, `ghosts`,
  `deconstruct`, `upgrade`, `paste`, `placements`, `nearest_water`, `conflicts`, `build_path`, `grid`, `pole_route`,
  `belt_route`, `belt_upgrade`, `rail_route`, `train_stop`, `train`, `clear_cliffs`, `heat_budget`, `outpost`, `rebuild`, `blueprint_save`,
  `blueprint_capture`, `blueprint_list`, `blueprint_place`, `blueprint_rename`, `blueprint_delete`.
- `circuits-settings`, wires, machine settings: `circuit_set`, `wire`, `circuit_gate`, `gates`, `circuit_audit`, `configure`,
  `assembler_batch`, `requests`.
- `movement-combat`, walks, enemies, vehicles, death: `move_to`, `retreat_guard`, `kite`, `recover`, `turrets`,
  `rearm`, `artillery`, `shoot`, `use_item`, `equip`, `vehicle`, `equipment`, `turret_feeds`.
- `analysis`, factory reads: `progress`, `research`, `research done`, `science`, `supply`,
  `bottleneck`, `trace`, `labs`, `inspect`, `ports`, `power`, `fuel_budget`, `game_alerts`, `belt_gaps`, `belt_flow`,
  `pipe_gaps`, `danger`, `drill_sites`, `ores`, `stock`, `reservations`, `logistics_audit`, `construction_robots`,
  `shortages`, `damage_log`, `dependency`, `ingredient_gap`, `robot_losses`, `losses`, `alerts_digest`, `requester_rate`.
- `waits-queues`, waits, queues, standing orders, urgent wakes, harness updates: `wait_until`, `sleep
  --until`, `wait_ticks`, `sleep_check`, `queue_submit`, `queue_status`, `queue_edit`, `queue_cancel`, `queue_pause`,
  `queue_repeat`, `plan save`, `plan run`, `plan list`, `stop`, `order_set`, `orders`, `order_remove`, `orders_pause`,
  `orders_resume`, `reminder_add`, `reminder_edit`, `reminder_ack`, `reminders`.
- `team`, board items, claims, `team:` and `OPERATOR:` lines: `board projects`, `board_review`, `board_retire`,
  `board_progress`, `board_critical`, `board_focus`, `lessons`, `lesson_add`, `lesson_edit`, `lesson_verify`,
  `lesson_review`, `ground_rule_add`, `ground_rule_retire`, `ground_rules`, `review`, `lookahead`, `networks`,
  `boilers`, `tells`.
- `stream-people`, stream profile, viewers, players: `profile`, `profiles`, `confess`, `chronicle`, `chat_ack`,
  `operator`, `poll`, `players`, `vote`, `votes`, `restore`.
- `space-age`, rockets, platforms, planets, remote queue lane, spoilage, Gleba: `platforms`, `platform NAME`,
  waits `platform_arrived` and `platform_left`, `platform_create`, `platform_schedule`, `platform_rename`,
  `platform_endurance`, `platform_supply`, `platform_plan`, `platform_bom`, `platform_production`, `platform_defense`,
  `platform_rearm`, `platform_digest`, `platform_tiles`, `platform_lanes`, `platform_gate`, `demolishers`, `shipment`,
  `fleet`, `min_payload`, `launch`, `silo`, `cargo`, `load_silo`, `silo_stage`, `pods`, `preflight`, `land`, `drop`,
  `freight_audit`, `where_is`, `agriculture`, `eggs`.
