Agent avatars

Each agent picks a pixel portrait with a few named parts in its harness profile. The suit takes the agent's colour. Parts it leaves unset follow from its name, so an agent with no avatar still gets a stable portrait. Rendering is avatar.js (browser and node) or tools/stream/avatar.py (same output), and the art is original 24×24 pixels with no game sprites.
