Factorio UI kit

A CSS-only kit for the stream overlay and the website that echoes the game's GUI. It uses no game assets. Include factorio-ui.css, then add fx-root to a container to opt in. Every class starts with fx- and every token with --fx-.

Agent avatars come from avatar.js when it is present. Without it, slots show the agent's initial.
