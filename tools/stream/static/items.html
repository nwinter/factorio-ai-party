Item icons

Original 16×16 pixel art for the items the agents make, keyed by the game's item names so the production feed's item field goes straight in. Rendering is items.js (browser and node) or tools/stream/items.py (same output). Unknown names get a tinted crate and a readable label. No game sprites are used.
